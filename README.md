# SuperDocs Growth Task

## Overview
This repository contains the planning and assets for the SuperDocs GTM / Growth Engineer task. 
The goal of this task is to prove the ability to build automated, AI-driven Go-To-Market and Growth engines that do the work of a whole team.

## Implementation Plan

### Task 1: Build a Growth Machine (Core Task)
- **Objective:** Build an automated system that finds a specific target audience, researches them, and drafts personalized outreach.
- **Rules:** Must run end-to-end automatically. **CRITICAL:** Cannot actually send messages to any real person or company. Output must be synthetic or routed to our own accounts.
- **Deliverables:** 
  - The working machine (e.g., Python scripts + prompts, or n8n/Make automation files).
  - One real piece of generated work (e.g., an outbound email sequence or a landing page).
  - A 1-page measurement write-up (what numbers prove it works, where it breaks at 10x scale).

### Task 2: Assigned Build
- **Objective:** The Compliance Engine built in the Engineering task (`doctask-shreekant` repository). 
- **Status:** ✅ Complete.

### Task 3: Use Cases & Buyers
- **Objective:** Map out ~10 real-world use cases for SuperDocs.
- **Deliverables:**
  - Name real companies and specific roles that would buy it.
  - Sketch the opening conversation strategy.
  - Note: Safe to document if a market is actually a *poor* fit, as long as it is backed by evidence.

### The Clip Task
- **Objective:** A 15-30 second screen recording with voiceover selling a specific feature.
- **Assigned Feature:** "An AI agent signs itself up."
- **Deliverables:** The video file / unlisted link.

### Task 4: Demo Video & Write-up
- **Objective:** A 3-5 minute video demonstrating the Growth Machine (Task 1) and the Compliance Engine (Task 2).
- **Deliverables:**
  - The video file / unlisted link.
  - A 1-page honest reflection on what was built, trade-offs made, and honest numbers.
